Timegrapher

時計師のタイムグラファーを、iPhoneに。

1本目は無料 · Proは買い切り · iPhone · iOS 17以降

App Storeで見る

日差・振り角・片振りを、約30秒で。 TimegrapherはiPhoneのマイクで機械式時計の音を聞き取り、コレクション、すべての計測結果、各時計の価値をひとつの場所にまとめます。

iPhoneで機械式時計の精度を測る方法

  • 日差・振り角・片振り

    1日あたりの進み・遅れ、テンプの振り角、チックとタックの対称性。振動数は18,000から36,000振動まで自動で検出します。

  • 安定した計測

    部屋の騒音レベルを追跡し、突発音を除外します。振り角はお使いのキャリバーのリフト角から算出します。

  • コレクション

    写真、リファレンス、ムーブメント、リフト角とともに各時計を登録。すべての計測を保存してグラフにします。「写真から識別」でブランドとモデルを提案します。

  • 1日着用したときの日差

    今日と明日、文字盤を撮影します。写真とiPhoneの時計を比べて、腕の上で時計がどう動いたかを表示します。

  • 資産としての価値

    お使いのリファレンスのChrono24の売り希望価格と、iPhone内で計算した中央値。

  • 磁気検査

    ヒゲゼンマイの磁気帯びは、時計が突然進みはじめる最も多い原因です。iPhoneの磁気センサーで、磁気抜きが必要かどうかがわかります。

よくある質問

iPhoneで機械式時計の精度を測れますか？

はい。TimegrapherはiPhone内蔵のマイクで時計の音を聞き取り、時計師のタイムグラファー（歩度測定器）と同じように働きます。約30秒で、日差（1日あたりの進み・遅れ）、振り角（テンプが振れる角度）、片振り（チック音とタック音のずれ）を表示します。

自動巻きと手巻きの時計に対応しています。1本目は無料で、サブスクリプションはありません。App Storeで見る

Timegrapherで時計を測るには？

  1. 時計を巻き上げ、静かな場所に移動します。
  2. 時計を追加をタップし、ムーブメントと、わかればリフト角を入力します。
  3. 測定をタップし、iPhoneの下端を時計にしっかり当てます。風防の上が最適です。
  4. そのまま動かさずに待ちます。0:30で自動停止し、日差・振り角・片振りと判定が表示されます。

日差・振り角・片振りは、どのくらいなら良好ですか？

Timegrapherが判定に使う基準は次のとおりです。

  1. 日差：±5秒以内ならクロノメーター基準内。±15秒までなら日常使いに問題ありません。±30秒を超えたら調整が必要です。
  2. 振り角：巻き上げた状態で文字盤を上にして250°〜315°なら健全です。220°を下回るとオーバーホールが近く、200°未満なら油の劣化が考えられます。315°を超えるとあおりの危険があります。
  3. 片振り：0.3ms未満なら良好。0.8ms以上で調整を検討し、1.5msを超えるとずれが目立ちます。

日差は姿勢によって変わるので、文字盤上・文字盤下・りゅうず下などをメモしておきましょう。姿勢別に測定なら各姿勢を順番に測れます。

時計が磁気を帯びているか確かめるには？

ヒゲゼンマイの磁気帯びは、機械式時計が突然進みはじめる最も多い原因で、日に数分進むこともあります。TimegrapherはiPhoneの磁気センサーで確認します。磁気を検査をタップし、まず周囲の磁場を測り、次に時計をiPhoneの背面に当てます。その差が答えです。

マグネット式のケース、ウォレット、マウントは先に外してください。結果はすべて保存されるので、磁気抜きの前後を比べれば効果を確認できます。

リフト角は何度にすればいいですか？

リフト角はムーブメントごとの値で、Timegrapherは振り角の計算に使います。スイス製ムーブメントには52°のものが多いものの、違う値のものも多いので、お使いのキャリバーの値を調べてください。リフト角の誤りは、スマートフォンのアプリが振り角を誤って表示する最大の原因です。日差と片振りはリフト角に左右されません。

スマートフォンのタイムグラファーは、作業台の測定器と比べてどのくらい正確ですか？

Timegrapherは1つひとつのチック音をミリ秒以下の精度で捉え、数千回分をiPhoneの時計と照合します。作業台の測定器と同じ原理です。静かな部屋でしっかり密着させると最も良い結果が得られます。Bluetoothイヤホンは音を圧縮するため、接続を切ってiPhone本体のマイクを使ってください。

表示される値は目安です。オーバーホールの判断は、作業台の測定器と時計師の判断を優先してください。

1日着けたときの精度もわかりますか？

はい。写真で測定は、1日あけて撮った文字盤の写真2枚を比べます。写真には撮影した正確な時刻が記録されるので、秒針の位置から、着けている間に時計がどれだけ進んだか遅れたかがわかります。

クオーツ時計にも使えますか？

いいえ。クオーツ時計は水晶振動子で時を刻み、針を1秒に1回動かすため、聞き取るテンプがありません。Timegrapherは自動巻きと手巻きの機械式時計用です。

Timegrapherは無料ですか？

1本目の時計は、すべての計測とともにずっと無料です。Timegrapher Proは買い切りの購入で、登録できる時計の数の制限がなくなります。サブスクリプションではなく、同じApple Accountの端末なら購入を復元できます。

Timegrapherは音を録音しますか？

いいえ。音はその場で解析され、録音・保存・送信されることはありません。コレクションはiPhoneの中にとどまります。任意の価格チェックは時計のリファレンスでChrono24を検索し、写真から識別はタップしたときだけ、その写真をAppleのPrivate Cloud Computeに送ります。プライバシーポリシー（英語）

プライバシーポリシーを読む（英語）

  • マイクの音はその場で解析され、録音も保存もされません。
  • コレクションと計測結果はiPhoneの中だけに保存されます。
  • 任意の価格チェックは、時計のリファレンスでChrono24を検索します。
  • 「写真から識別」は、タップしたときだけその写真をAppleのPrivate Cloud Computeに送ります。Appleは保存せず、開発者が見ることもありません。
  • 「原子時計」タブはAppleの時刻サーバーから時刻を取得します。個人データは含まれません。
