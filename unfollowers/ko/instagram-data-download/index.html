Unfollowers

인스타그램 데이터 내려받는 방법 (JSON 내보내기)

인스타그램에서는 내 계정 데이터의 사본을 내려받을 수 있어요. 내보내기 파일에는 내 팔로워와 내가 팔로우하는 계정의 전체 목록이 들어 있어요. Unfollowers는 이 파일을 읽어서 누가 나를 언팔했는지 보여 줘요. 아래는 iPhone 인스타그램 앱 기준의 방법이에요.

선택할 항목

정보
팔로워 및 팔로잉
기간
전체 기간
형식
JSON

  1. 메뉴 열기

    인스타그램 앱에서 오른쪽 아래의 프로필 사진을 누르고, 오른쪽 위의 메뉴(☰)를 눌러요.

  2. 계정 센터

    계정 센터를 눌러요. 일부 계정에서는 이름이 Meta 계정이에요.

  3. 내 정보

    내 정보 및 권한을 누른 다음 내 정보 내보내기를 눌러요.

  4. 내보내기 만들기

    내보내기 만들기를 눌러요. 인스타그램 프로필을 고르고 다음을 눌러요.

  5. 기기로 내보내기

    기기로 내보내기를 선택해요. 파일이 iPhone에 저장돼요.

  6. 데이터 고르기

    다음 화면에서 내보낼 정보를 골라요. 연결 항목에서 팔로워 및 팔로잉을 체크해요. 가장 많이 소통하는 사람도 보려면 좋아요, 댓글, 스토리 상호작용도 체크해요. 나머지는 체크를 풀면 파일이 작아져요.

  7. 전체 기간, JSON

    기간은 전체 기간을 골라요. 형식은 JSON을 골라요. Unfollowers는 HTML 형식을 읽지 못해요.

  8. 내보내기 시작

    내보내기 시작을 눌러요. 인스타그램이 파일을 준비해요. 보통 몇 분 걸려요.

  9. ZIP 내려받기

    파일이 준비되면 인스타그램이 알림을 보내요. 내 정보 내보내기로 돌아가서 파일을 내려받아요. 인스타그램이 비밀번호를 물을 수 있어요. 비밀번호는 인스타그램 화면에 직접 입력해요. ZIP 파일을 파일 앱에 저장해요.

  10. Unfollowers로 가져오기

    Unfollowers를 열고 가져오기 버튼을 누른 다음 ZIP 파일을 골라요. 압축을 풀 필요는 없어요.

알아 두면 좋은 점

파일 두 개로 떠난 사람을 알 수 있어요

내보내기 파일 하나에는 하루 동안의 팔로워 목록이 들어 있어요. 몇 주마다 새 파일을 가져오세요. Unfollowers가 비교해서 지난번 이후에 떠난 사람을 보여 줘요.

파일은 4일 동안 내려받을 수 있어요

인스타그램은 완성된 내보내기 파일을 4일 동안 보관해요. 그 뒤에는 새로 만들어요.

“팔로워 목록을 찾지 못했어”

내보내기 파일이 HTML 형식이거나 팔로워 및 팔로잉이 체크되지 않았을 때 Unfollowers가 이 메시지를 보여 줘요. 팔로워 및 팔로잉을 넣어서 JSON 형식으로 새로 내보내요.

더 오래 걸릴 수도 있어요

대부분의 내보내기는 몇 분 안에 끝나지만, 가끔 더 오래 걸려요. 준비되면 인스타그램이 앱과 이메일로 알려 줘요.

2026년 11월에 인스타그램 고객 센터의 안내와 비교해 확인한 방법이에요.

누가 나를 언팔했는지 확인해요

Unfollowers는 이 파일을 iPhone 안에서 읽어요. 나를 언팔한 사람, 나를 차단한 듯한 계정, 나를 맞팔하지 않는 사람을 보여 줘요. 로그인도 비밀번호도 필요 없어요.
